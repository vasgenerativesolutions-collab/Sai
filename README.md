# Sai Traders — Admin Web Portal

Web frontend build for the Sai Traders Enterprise Retail Operations and Live Inventory Management system.

## Features
- **Live Inventory Management**: Real-time stock tracking with dedicated Godown isolation (Sarees).
- **Color Variant Management**: Grouped saree catalog with color swatches and variant stock allocation.
- **Sales Analytics & Audit Log**: Real-time transaction history and daily sales tracking.
- **Media & Photo Studio**: High-resolution saree photos and drape video management.
- **TallyPrime & WhatsApp Integration**: Direct integration with Tally ERP and Meta WhatsApp Cloud API.
